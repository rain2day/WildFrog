Current WildFrog development lives in:

```text
ios/WildFrogNative/
```

Archive contents:

- `prototype/`: legacy static HTML/CSS/JS mobile prototype.
- `index.html`: old redirect entrypoint to the prototype.
- `app-draft.md`: old product design draft notes for the web prototype.
